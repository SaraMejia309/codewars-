# #05 - Opposite number

## Problem Description
Very simple, given a number, find its opposite (additive inverse).

**Examples:**
- `1`: `-1`
- `14`: `-14`
- `-34`: `34`

---

## Solución Propuesta

### Algoritmo
1. **Inverso Aditivo:** Se obtiene el signo opuesto de cualquier número simplemente multiplicándolo por `-1` o antecediendo el operador unario `-`.
2. **Retorno:** Se devuelve directamente `-number`.
