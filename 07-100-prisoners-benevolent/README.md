# #07 - 100 prisoners riddle (Benevolent guard)

## Problem Description
This kata is part of a series based on the famous 100 prisoners riddle. 100 death row prisoners numbered 0-99 are offered a chance to survive with the help of a benevolent guard.

---

## Solución Propuesta

### Algoritmo
1. **Acción del Guardia Benevolente:** En esta variante del acertijo, el guardia dispone la habitación de forma favorable para garantizar la supervivencia de los prisioneros.
2. **Retorno Directo:** La función debe retornar la disposición del arreglo `room` ingresado.
